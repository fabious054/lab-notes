# Security

*Leia em português: [SECURITY.pt-BR.md](SECURITY.pt-BR.md)*

This repository holds write-ups, raw measurement data and small probe
snippets. It ships no binaries and runs nothing on its own.

- Probe code here is short and readable on purpose. Read it before you
  run it, as with any code from the internet.
- Replication reports (issues) must contain only measurement output and
  hardware details. Never paste credentials, tokens or personal data.

## Reporting a problem

If you find a security problem (for example, code here that does
something other than what it says), contact the maintainer through the
repository owner's GitHub profile instead of opening a public issue.
