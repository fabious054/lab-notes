reading:
  dip < 1: the first 0.5 ms run slower than steady state (per-core wake-up ramp, finding 0003).
  2-10 ms < 1: a sustained slowdown, the signature of finding 0001; check it in the threads that
  did NOT sleep (idle < 1 ms): a per-core ramp cannot slow them, a chip-wide current limit can.
  stream (DRAM) vs stream-l3 vs chase (stalls, little bandwidth) vs stream-rw: which memory activity lowers
  the clock while it runs and afterwards; stream-slices vs stream at 1 thread/core (part-3 discrepancy);
  lead 100 ms: how low the clock goes with longer streaming, and how fast.
  APERF/MPERF and B/V tell a real clock drop from an issue limit.
