# Segurança

*Read in English: [SECURITY.md](SECURITY.md)*

Este repositório guarda textos, dados brutos de medição e pequenos
trechos de código de probes. Ele não distribui binários e não executa
nada sozinho.

- O código de probe aqui é curto e legível de propósito. Leia antes de
  rodar, como qualquer código da internet.
- Relatos de replicação (issues) devem conter só a saída da medição e
  detalhes do hardware. Nunca cole credenciais, tokens ou dados pessoais.

## Como reportar um problema

Se você encontrar um problema de segurança (por exemplo, código aqui que
faz algo diferente do que diz), fale com o mantenedor pelo perfil do
dono do repositório no GitHub em vez de abrir uma issue pública.
